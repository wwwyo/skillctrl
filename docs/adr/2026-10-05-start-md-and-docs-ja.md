# Consolidate first-time setup in docs/start.md and Japanese docs under docs/ja/

- Status: Accepted
- Date: 2026-10-05

Consolidated first-time setup into `docs/start.md`, a self-contained
procedure an AI can follow through CLI installation, acquisition
dependencies, skill installation, and activation verification. The
distributed skill drops initial setup, and the Japanese versions of the
maintained guides — including their bundled resources — are collected under
`docs/ja/`. Also settled `cd` as the only way to select the target
repository. Part of [PR #9](https://github.com/wwwyo/skillctrl/pull/9),
shipped in v0.3.0.
